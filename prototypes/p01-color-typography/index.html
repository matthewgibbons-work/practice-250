P1 · Color + Typography

Two pages for two very different readers: a museum label for adults in a quiet gallery, and a fan page for a loud Saturday-morning robot cartoon. Below, each page's colors, fonts, the reasons for them, and proof that every text color is readable.

The museum label

Open the museum label page

Palette

  • Gallery Wall, #f4f1ea: page background
  • Ink, #222222: body text
  • Stone, #5c5346: captions and small print
  • Exhibit Teal, #1f5f63: headings, links, and the header band

Fonts

  • Headings: IBM Plex Sans, weight 600 (fallback: Arial, sans-serif)
  • Body text: Source Serif 4, weight 400 (fallback: Georgia, serif)

Why these choices

A gallery wall is usually off-white, and the label should feel like part of it, not a poster, so the background is a warm cream and the text is near-black. Teal is the one color, used for headings and links, because it reads as calm and official. Stone gray is only for the small print, like the maker, year, and materials under each object, which people read last.

IBM Plex Sans is a plain, solid sans-serif that IBM made for its own products, which suits an exhibit about 1980s computers. Source Serif 4 is for the paragraphs because it's easy to read for a few minutes standing up, like a book.

The fan page

Open the fan page

Palette

  • Robot Blue, #1e2a9e: background and gradient start
  • Laser Purple, #5a1a9a: gradient end
  • Bolt Yellow, #ffe14d: headings, links, and the badge
  • Chrome White, #ffffff: body text

Fonts

  • Headings: Bungee, weight 400 (fallback: system-ui, sans-serif)
  • Body text: Nunito, weights 400 and 800 for the badge and current nav link (fallback: system-ui, sans-serif)

Why these choices

Saturday-morning cartoons were bright and loud, so the page is dark robot blue fading into purple, like the show's space background, with lightning-bolt yellow for the headings and links. Body text is white, because yellow paragraphs on blue would be tiring to read for long.

Bungee looks like the blocky letters on a toy box or a robot's chest plate, so it's only for headings. Nunito is round and friendly for the paragraphs, and it stays readable on a phone, where most fans will see it.
